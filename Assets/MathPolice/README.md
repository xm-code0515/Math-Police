# 见习小侦探 / Math Police Demo

打开 `Assets/Scenes/SampleScene.unity`，点击 Unity 的 Play 进入主菜单。开始游戏进入第一关，读取存档打开独立读档窗口。

## 操作与演出

- 第一关开场使用 `Art/open/background.png` 白底，按点击顺序累积淡入 `1.png` 至 `6.png`；音符、问号、思考气泡和贴纸延迟依次淡入。动画结束后接受下一次点击，第六格之后淡入案件对白。
- 第一关供词页在提示正文上方显示蓝色“提示”和 `Vector (14).png` 图标。关键供词教学仅亮起圆角框，不保留矩形高亮底板。
- 五关使用 2026-09-20 修订剧本，共 237 条双语对白；文档中的重复供词汇总不重复播放，关键供词仍保留于对话和推理本中。

- 主菜单默认浅蓝按钮，移入切换蓝色、放大并播放 button1；按下缩小、点击播放 button2。开始和读档均有黑屏淡入转场，背景铺满屏幕。
- 点击对话框补全本句，再次点击进入下一句，播放 button2。自动模式等待本句显示完成及设定间隔。跳过每 0.12 秒推进一句，再次点击停止跳过；转场期间停止按钮仍可用，当前转场完成后停住，所有供词仍记入本案记录。
- 嫌疑人开始发言时，从警局渐变到审讯室，主角、警察和对话框淡出，嫌疑人和橙色对话框淡入。嫌疑人之间只切换立绘，保留对话框。审讯中的主角／警长插话保留当前嫌疑人，仅换为蓝色对话框。进入复盘段落后回到双方角色，背景保持审讯室。非发言角色略微变灰。
- 最后主角和对话框淡出，嫌疑人从左到右排列。鼠标移入立绘的非透明部分显示蓝色轮廓，点击固定选择，再提交判断。供词在人物上方，姓名在下方。答对播放 correct，答错播放 wrong。
- 每页最多五名嫌疑人，更多人数可翻页；图像大小自适应，并与底部提交按钮分开。长供词可在推理本中完整阅读。
- 本子 → 记录：仅本案历史对话，按左、右页顺序填入，底部按钮翻页。
- 本子 → 放大镜：左侧显示各嫌疑人的供词；右侧默认推演草稿，底部切换表格／草稿，内容均保留。画笔支持颜色、粗细，橡皮仅擦画布。表格真／假互斥，犯人勾选独立。清除只作用于当前右页。
- 设置支持中英文、文字速度、自动速度、音乐音效、全屏、分辨率、字体大小和对话框透明度。全屏默认开启，开关圆点平滑滑动。确定保存，取消恢复打开窗口时的偏好。主菜单只显示常规、音频、显示、文字四类。
- 全屏和分辨率在独立播放器中应用；编辑器使用 Game 视图尺寸，设置不会改变编辑器桌面窗口。
- 四个存档位保存缩略图、时间、对话位置、记录、判断、绘画、表格、右页类型和随机嫌疑人形象。覆盖先确认；游戏内读档提示替换当前进度，主菜单直接选择存档并转场。
- 游戏设置中可以返回正式主菜单。退出游戏在编辑器中停止 Play，在独立播放器中退出程序。

## 添加关卡

### 第一关教程

`tutorial: true` 启用第一关教学。首次关键供词完整显示后暂停自动／跳过，聚光框圈出关键文字；点击后淡出恢复对话。选人界面按顺序引导：嫌疑人 → 打开推理本 → 关键供词 → 草稿 → 切换表格 → 记录 → 关闭 → 左上角记录入口。需要操作按钮的步骤只接受该目标点击，其他步骤点击继续，不会穿透到背景。教程进度跟随该存档，开始新游戏重新教学。

第一关笔记左侧另有一真两假的假设检验提示，其他关卡不显示。正确提交后固定选中真正犯人，立绘不再响应悬停或点击；“查看推理”仅重新打开结果。

漫画引用 `Art/tutorial-intro.png`，教学箭头引用 `Art/ui/Vector (9).png`，高亮边框及提示框引用 `Art/ui/box-body (1).png`。Play 模式可运行 `Math Police/Run tutorial and interaction fix checks` 验证教程、取消跳过及通关锁定。

当前正式关卡按 `chapter_01.json` 至 `chapter_05.json` 排列：失踪的蓝宝石项链、消失的五百万、停电中的黄金面具、消失的极光芯片、午夜拍卖会凶案。通关后使用“下一档案”顺序切换。最后一关保留通关画面，并提示暂无下一档案。

五份中文剧本共导入 307 段对话，另配对应英文译文。只提取人物和旁白的台词，省略场景动作、设计说明、题目及答案列表；重复的关键供词汇总不重复播放。为完整显示，少数长段落在标点处拆句，正文不改写。第一关先展示捡到办案笔记的六格漫画，玩家点击后通过黑屏淡入进入警长对话。漫画仅在开始新游戏时展示，正常读档不重播。第二至第五关的旁白均为黑底。

`suspects[].testimony` 只保存关键供词，用于笔记左页、选人气泡及正文高亮。完整闲聊与问答保存在 `script`。对话与历史记录中匹配关键供词的文字使用橙色粗体，逐字显示和翻页保持完整标签。长对话会自动向上扩展对话框，底边及跳过／自动按钮位置不变，以兼容最大字号和英文文本。

正式五关检查入口为 `Math Police/Run five chapter checks`（Play 模式）；原互动检查继续使用旧演示关作为独立测试数据，不改动真实存档。

复制 `Cases/chapter_01.json`，在场景 `MathPolice_Demo` 组件的 Case Files 数组中添加 JSON。`StartCase(index)` 生成对应关卡；主菜单从第一个关卡开始。

| 字段 | 含义 |
|---|---|
| id | 唯一稳定的案件标识，读档时匹配 |
| title / summary / explanation | 双语对象 `{ "zh": "中文", "en": "English" }`，分别为标题、条件和推理解释 |
| suspectCount | 人数，必须等于 suspects 长度，至少 2 人 |
| truthCount | 说真话的人数 |
| culpritIndex | 犯人的数组下标，从 0 开始 |
| suspects | 每人包含 name、testimony 双语文本，gender，以及可选 rule |
| script | 完整有序对话，每项包含双语 speaker、text、role、stage、suspectIndex 和表情；配置后不再自动补充供词或结尾台词 |
| introduction | 旧格式开场对话；仅在没有 script 时自动追加 suspects 供词和结尾提示 |

`gender` 使用 `male` / `female`，也兼容 `boy` / `girl`、男／女。形象从 `Art/suspect/boy` 或 `girl` 随机选取，同性别图库用完前尽量不重复。存档保存「图库/文件名」，读档恢复原形象；旧存档会首次补充分配。删除或改名图库文件后，相应缺失形象会重新选择。

新增素材后，可手动扩展组件的 Boy Portraits / Girl Portraits，或执行 `Math Police/Set up demo in current scene` 重新扫描、绑定素材。该菜单保留已配置的关卡列表。

### 剧本演出字段

- `role`：`player`、`officer`、`suspect`、`narrator`，控制发言姓名和对话框颜色。
- `stage`：`narration` 为黑底旁白，保留全部对话和顶部界面；`station` 为警局双人对话；`interrogation` 为审讯；`debrief` 为审讯室内的双人复盘。
- `suspectIndex`：审讯阶段当前显示的嫌疑人（从 0 开始），警长／主角插话时也保留该值，立绘不切回双人。
- `expression`：发言角色的表情。主角支持 `normal`、`smile`、`thinking`；警察支持 `normal`、`smile`、`smile2`、`laugh`。
- `playerExpression` / `officerExpression`：可选，指定另一角色的表情；不填写则保留前一表情。

外部剧本导入器可直接生成以上 JSON 结构；目前提供数据接口，不包含自然语言剧本解析器。

### 可选逻辑校验

所有嫌疑人都提供 rule 时，加载前验证唯一答案，支持最多 16 人：

- `culpritIs` / `culpritIsNot`：target 为所指嫌疑人的下标。
- `statementTrue` / `statementFalse`：target 为所指供词的下标。
- `fact`：factValue 指定案件事实的真假。
- `all` / `any` / `implies`：terms 数组包含两个子规则，分别表示而且、或者、如果前项则后项。条件句只在前项真、后项假时为假。

未提供完整规则时，按作者给出的 culpritIndex 判定，不自动理解自然语言。作者需要保证文字、规则和答案一致。

旧奖章演示关保留于 case_001.json 和 Legacy Case Files，仅供旧存档使用，不占用正式五关顺序。

## 存档与实现

存档和设置位于 `Application.persistentDataPath/MathPoliceDemo`，不会写入 Assets。版本 3 保存形象、右页模式与教程完成状态／当前步骤，兼容版本 1、2 旧存档；原子替换文件，保留覆盖确认。不兼容或损坏存档会提示失败并保留当前进度。

界面使用 1600×900 逻辑坐标的 IMGUI 绘制，鼠标、触摸、按钮、滑块、滚动、画布由新版 Input System 驱动。背景全屏裁切铺满，交互元素等比适配；空格推进对话，Esc 关闭窗口或打开设置。

中文使用系统动态字体（Microsoft YaHei / SimHei / Noto Sans CJK SC）。Windows 环境具备字体；跨平台发布应配置有授权的内置字体。

## 验证

编辑器菜单 `Math Police/Validate case library` 校验关卡。Play 中运行 `Run menu and presentation checks`，通过虚拟鼠标检查主菜单悬停／按压、角色与黑屏转场、音频映射、随机形象、立绘选人、笔记切换保留、全屏开关、磁盘存读档、覆盖确认、旧存档兼容、九人自适应分页。测试存档写入项目 Temp 下的独立目录，不占用真实存档位。旧的两个测试菜单也是此测试入口。
